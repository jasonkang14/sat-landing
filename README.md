# sat-reading-landing

Marketing landing page for the SAT Reading & Writing YouTube channel
([@kangsium](https://www.youtube.com/@kangsium)). Live at
[sat.kangsium.com](https://sat.kangsium.com/).

## Develop

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Publishes `dist/` to the `gh-pages` branch. The custom domain is set in
`public/CNAME`.
